# Number Guessing Game 🎯

A simple number guessing game built with Python.

## How to Play

The computer chooses a random number, and you try to guess it.

The game gives you hints to tell you whether your guess is too high or too low.

## Features

- 🎲 Random number generation
- 🔢 User guesses
- ⬆️ Higher/lower hints
- 🏆 Winning message
- 🔄 Simple and fun gameplay

## How to Run

Make sure Python is installed, then run:

```bash
python "number guessing.py"
